# Automated Cybersecurity Assessment and Monitoring System

## Project Overview

This project provides an authorized laboratory environment
for cybersecurity assessment, monitoring, alert logging,
dashboard visualization, and automated audit reporting.

## Components

1. Network Packet Monitor
2. Network Scanner
3. Web Security Scanner
4. Anomaly Detection
5. Security Alert Database
6. Security Dashboard
7. Automated PDF Audit Report

## Technologies

- Python
- Linux/Kali Linux
- SQLite
- Flask
- HTML/CSS
- ReportLab

## Project Workflow

Scanner
   ↓
Security Finding
   ↓
Alert Database
   ↓
Security Dashboard
   ↓
PDF Audit Report

## Testing

Testing was performed only against authorized laboratory
systems.

## Result

The integrated system successfully generated security findings,
stored alerts, displayed them on the dashboard, and generated
an automated audit report.
